Slack Integration

How to connect Slack:
  1. Go to api.slack.com/apps → Create New App → From Scratch
  2. Add Bot Token Scopes: channels:history, channels:read
  3. Install app to workspace → copy the Bot User OAuth Token (xoxb-…)
  4. Invite the bot to your channel: /invite @YourAppName
  5. Find your Channel ID in the Slack URL: ends with /CXXXXXXXX
  6. Paste the token + channel ID below and save settings
Slack threads mentioning Jira tickets will appear in the Intelligence panel after the next sync.
